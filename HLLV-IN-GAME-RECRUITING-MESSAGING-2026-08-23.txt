IMPLEMENTATION
- Uses HLLV RCON SetWelcomeMessage for deployment text.
- Uses ServerBroadcast for top-left timed notices and clears with an empty broadcast.
- Uses MessagePlayer for one-time first-visit recruiting message.
- Messaging failures are isolated from telemetry; RCON stats collection continues.
- No new Railway variable is required. HLL_RCON_RECRUITING_ENABLED is an optional kill switch and defaults true.
