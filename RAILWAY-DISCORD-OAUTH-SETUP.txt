5TH CAVALRY WEBSITE — DISCORD IDENTITY VERIFICATION

This website already contains the Discord OAuth routes. The Verify With Discord button is disabled only when the website Railway service does not have a Discord OAuth Client ID and Client Secret.

ADD THESE VARIABLES TO THE WEBSITE RAILWAY SERVICE (not only the Battalion Clerk worker):

DISCORD_CLIENT_ID=<Discord Application ID>
DISCORD_CLIENT_SECRET=<Discord OAuth2 Client Secret>
DISCORD_OAUTH_REDIRECT_URI=https://www.5thcavgaming.com/recruiting/discord/callback

Recommended existing variable:
WEB_SECRET_KEY=<long random secret>

The code now accepts WEB_SECRET_KEY as an alias for SECRET_KEY.

DISCORD DEVELOPER PORTAL:
Open the same Discord Application used for your Battalion Clerk (or a dedicated website OAuth app). Under OAuth2, add this exact redirect URL:
https://www.5thcavgaming.com/recruiting/discord/callback

The URL must match exactly, including https and /recruiting/discord/callback.

After adding the Railway variables, redeploy the WEBSITE service.
